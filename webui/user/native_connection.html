Client login / migration

Use this account in another signed game client by entering the same server address, account ID and client login password.

Reinstalling a differently signed client may remove that client's local files. Your progress remains on this server. Export a backup first; importing is not needed just to log in.

Set / generate client login password

Existing passwords are stored as bcrypt hashes and cannot be recovered. Only a password explicitly saved here can later be revealed or copied.

Changing this password replaces the old game login password. It preserves your account progress, authorization keys and current sessions.
