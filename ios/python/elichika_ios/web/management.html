Quick guide

  • The Elichika button starts visible. Hide it for MV playback; hold the upper-right corner for two seconds to reopen the combined server and game menu.
  • Choose Game settings in the same menu to adjust FOV, orientation and intro speed.
  • Place existing packs in this app’s Elichika/packs folder through Files or Finder. Large libraries can use the external-folder option.
  • Finish game downloads and MV playback before installing mods or changing databases. Restart the game to load edited assets.
  • iOS can suspend an app in the background. Keep this app open while downloading or serving other devices.
  • The integrated app’s local database is separate from the Mac server. Export and import accounts to move them.
